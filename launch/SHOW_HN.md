# Show HN

## Title

Show HN: My coding agent gives me side quests while it works

## Post

Coding agents made an odd new attention gap: the agent is busy for five or ten minutes, but I am still watching the terminal or opening an endless feed.

I made Meanwhile, an open catalogue and Agent Skill that lets the coding agent offer one small side quest while it keeps working.

Examples:

- a one-minute no-tab reset;
- a lesson tied to the stack currently being changed;
- a finite game;
- a real click-path check when generated source is not enough;
- one taste or proof question only the person can answer.

The restraint rules matter more than the recommendations: once per work session, never during active failure handling, stop after a decline, and no completion tracking. The person never needs to return to the website. The agent sends the prompt or destination directly.

It is one `SKILL.md` plus a static JSON catalogue, so it works with Codex, Claude Code, Cursor, Gemini CLI, OpenCode, and Copilot. The site is plain HTML and JavaScript on GitHub Pages.

Site: https://vaddisrinivas.github.io/meanwhile/

Source: https://github.com/vaddisrinivas/meanwhile

I would especially value feedback on when an offer feels useful versus annoying, and which quest defaults are actually worth keeping.
