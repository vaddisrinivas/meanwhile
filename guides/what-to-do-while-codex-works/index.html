Guide

What to do while Codex works

Codex can continue through implementation and verification while you step away. Use the wait for something with a clear edge: one check, one reset, one idea, or one tiny game. Keep required questions in the coding task so Codex can interrupt normally.

Use the wait honestly

Do not start a ten-minute activity for a ninety-second command. Use a no-tab micro quest for short waits and a small journey only when Codex projects at least five unattended minutes.

Match the current task

Learning sticks when it touches the code already open. If the task involves OAuth, trace an OAuth exchange. If it involves Compose, check the exact performance pattern under review.

Come back to proof

The side quest is not evidence that the work succeeded. When Codex finishes, inspect the claimed proof boundary: source, local run, browser, device, live service, or your own acceptance.
